\# Lessons Learned



This project provided hands-on experience with Infrastructure as Code, Kubernetes, GitOps, and cloud-native observability.



\---



\## Infrastructure as Code



Terraform simplifies infrastructure provisioning by making deployments repeatable and version controlled.



\---



\## GitOps



Argo CD continuously reconciles Kubernetes resources with the Git repository.



Any Git commit automatically becomes the desired cluster state.



\---



\## Kubernetes



Namespaces are critical for organizing workloads.



Using an incorrect namespace can lead to confusion even when applications are healthy.



\---



\## Observability



Deploying Prometheus and Grafana alongside applications makes it easier to monitor cluster health and application performance.



\---



\## Documentation



Well-structured documentation significantly improves project maintainability and helps reviewers understand the project quickly.



\---



\## Version Control



Keeping infrastructure, Kubernetes manifests, and documentation together in Git provides a complete history of the project and simplifies collaboration.
